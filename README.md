# 🌤️ WeatherNow

A beautiful weather application built using HTML, CSS and JavaScript.

## Features

- Search weather worldwide
- Current location weather
- 5-day forecast
- Temperature graphs
- Dark Mode
- Light Mode
- Celsius/Fahrenheit
- Search history
- Favorites
- Dynamic backgrounds
- Installable (PWA)

## Technologies

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- Open-Meteo API
- Chart.js
